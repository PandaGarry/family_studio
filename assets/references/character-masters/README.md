# Family Studio — character reference masters

Эта папка содержит неизменённые исходные character masters, view crops и `character.json`, которые разрешено использовать в Family Studio. Это **референсы для моделирования**, не готовые Family Studio-рендеры, текстуры или утверждённые финальные дизайны.

- Перенос разрешён владельцем материалов для использования в Family Studio.
- Пиксели и JSON-карточки сохранены без редактирования.
- Проверка целостности: [`SHA256SUMS`](SHA256SUMS).
- Не использовать референсы как stock/CC assets или материалы для других проектов.

## Структура

Каждая папка `characters/{dad,mom,son}/` содержит turnaround, face master, crops front/three-quarter/side и `character.json`. Структура упрощена для работы; исходные названия и пиксели файлов сохранены.

На turnaround-листах есть зелёный reference-фон. Он является частью листа: не переносить его в материалы или окружение, не очищать исходник и не включать в финальный render. Проверять лицо и отдельные view crops по исходным пикселям.

Три `character.json` сохранены как есть. Это полезные визуальные заметки о пропорциях, палитре и identity, но не проверенные метрические измерения. В записи папы есть `hoodie_gray`, хотя на turnaround виден светло-серый crewneck без капюшона. Пользователь подтвердил crewneck для Family Studio (2026-11-01); исходный JSON не менялся, переопределение описано в [brief папы](../../../docs/series/dad-3d-model-brief.md).

## Motion references

Папка `motion/` содержит три PNG-листа walk/run и один MP4. На PNG-листах видны обрезания и стыковые артефакты; использовать их только как подсказки тайминга и направления поз, не как визуальный baseline. MP4 не просмотрен и не считается проверенным анимационным результатом. См. [ревизию reference assets](../../../docs/series/reference-assets-review.md).
