The scene has studio lighting and review cameras; it is saved/reopened by the browser Blender runtime.

Five native Cycles PNGs are in [`assets/renders/dad-hero-v1/`](../../renders/dad-hero-v1/): full-body front, three-quarter, profile and back at 512×896/64 samples, plus face close-up at 512×512/80 samples. These are actual Blender Cycles renders, not GUI screenshots.

**Status is draft, not professional final approval:** v1 is a static, procedural hero-model iteration for reference comparison. Its likeness, facial silhouette, hair/beard shaping, topology, UVs, materials and object intersections still need review/refinement; it has no armature, weights, facial rig or animation. A beauty render alone does not pass the topology or motion gates.
