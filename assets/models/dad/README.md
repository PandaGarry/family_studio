# Dad — R3 gray blockout

`dad-blockout.blend` is a real Blender 5.2.0 LTS project generated by executing [`tools/blender-wasm-runtime/src/dad_blockout.py`](../../../tools/blender-wasm-runtime/src/dad_blockout.py) in `@volter/blender-engine@0.1.148` inside Chromium WebAssembly. The saved document was reopened by a second Blender session during the smoke test.

This is **a technical, unapproved blockout**, not the final Dad model: one Blender mesh object contains disconnected primitive shells; topology is not production-ready; the character is not rigged or animated; likeness has not been approved. The home-look override is respected: light crewneck, no hood. Original `character.json` and references remain unchanged.

Native Cycles test images (360×640, 32 samples; denoising disabled by the upstream preview API) are in [`assets/renders/dad-blockout/`](../../renders/dad-blockout/). Technical verification and runtime limitations are recorded in [`docs/series/blender-wasm-runtime.md`](../../../docs/series/blender-wasm-runtime.md).
