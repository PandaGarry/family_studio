# Ревизия локальных character references и legacy 3D-прототипа

Дата проверки: 2026-11-01. Документ описывает материалы, включённые в Family Studio, и границы их использования. Перенос разрешён владельцем материалов; файлы и их происхождение описаны локально, внешние ссылки в рабочих документах не используются.

## Character references

В `assets/references/character-masters/characters/{dad,mom,son}/` сохранены turnarounds, face masters, crops front/three-quarter/side и исходные `character.json` всех трёх героев: 15 PNG + 3 JSON. Пиксели и JSON не менялись. Зелёный фон turnaround остаётся частью **референс-листа**, не персонажа. SHA-256 манифест находится рядом.

Папка `motion/` содержит три статичных walk/run PNG-листа и один MP4. На листах видны обрезания головы/тела и артефакты конечностей. Они годятся только для тайминга/направления поз; не использовать их как visual baseline или Blender-анимацию. MP4 не просмотрен и не считается проверенным.

Пользователь явно подтвердил домашний верх папы: светлый crewneck без капюшона. Значение `hoodie_gray` в исходном JSON сохранено, а override Family Studio отмечен в brief папы и README reference assets. Референсы не считаются stock/CC; разрешение владельца ограничено этим проектом.

## Legacy procedural 3D study

В рассмотренных технических материалах была отдельная Python/NumPy система параметрической геометрии, собственный software rasterizer и 21-костный rig с IK. Она использует собственную Y-up систему координат и создаёт меши численно; это не Blender-сцена, не `.blend` и не готовый Blender rig. Проверка файлов не обнаружила готового native Blender/Godot-проекта.

Упомянутые в техматериалах пропорции, позы и принципы IK можно использовать только как исходные идеи. Скриншоты и render-листы старого прототипа не совпадают по качеству с master-образом папы; в Family Studio они не приняты за стиль, не портированы в production и не заменяют Blender proof. Заявленные в старых заметках числа тестов здесь не воспроизводились.

Портирование такого кода потребовало бы перевести оси, материалы и skinning-контракт, а затем заново проверить геометрию/rig в Blender. Для текущей задачи выбран прямой Blender-first путь; старый эксперимент не является производственной зависимостью.

## Решение Family Studio

- Сохранять исходные reference masters и JSON неизменными; пользовательские overrides записывать отдельно.
- Геометрию строить вручную в Blender из согласованных references, не вырезать 3D-модель из зелёного turnaround.
- Внешние ассеты отдельно вносить в [реестр ассетов и лицензий](asset-ledger.md).
- Подробный runtime proof описан в [проверке Blender WASM](blender-wasm-runtime.md). R3 blockout ранее получил 9/10 как пропорциональная опора, но пользователь затем явно отклонил сам blockout как неподходящую базу. Процедурная R4 v1 получила 1/10 и отклонена. Оба набора файлов сохранены только в rejected archives и не являются hero-model references или стартовой геометрией.
