# Первый 3D-модельный бриф: мальчик в кепке P

Статус: рабочая спецификация v0.1 по загруженным пользователем референсам; **не утверждённый финальный дизайн и не готовая модель**. Первый 3D proof-of-style предлагается делать на нём: для этого героя есть turntable, крупный портрет и отдельная жестовая поза.

## Референсы

- `assets/references/modeling/boy-turnaround-panel.png` — фронт, 3/4, профиль; зелёный экран сохранён как часть reference plate, он не является частью персонажа или будущего окружения.
- `assets/references/raw/IMG_5976.png` — крупный портрет.
- `assets/references/raw/IMG_5979.png` — характерная pointing-поза.
- Исходные PNG — скриншоты; элементы телефона/видеоплеера и нижняя кнопка в turnaround/pose crops — не канон модели. Не сэмплировать их цвет и не использовать как texture.

## Канонические визуальные якоря — предварительные

- Компактные мультяшные пропорции: крупная округлая голова, большие карие глаза, короткий нос, выразительные брови и детский силуэт.
- Светлая мятная кепка с тёмной `P`; форма козырька и посадка кепки на лбу — важный элемент узнаваемости.
- Тёмно-каштановая фактурная причёска видна только частично/сбоку; профильные виды использовать для формы головы и ушей, но укладку под кепкой автор должен подтвердить.
- Коричневое мягкое худи с капюшоном, светлой надписью `ABC` и карманом; тёмные брюки и коричневая обувь.
- Характерная уверенная/озорная улыбка и указующий жест — один из вариантов acting, не постоянное выражение лица.

## Модельный подход

- Создать один базовый mesh, не разные картинки для каждого угла. Геометрию головы/щёк/челюсти/уха строить по front + 3/4 + profile; дополнительно проверять в близком кадре.
- Худи, кепку, волосы, обувь и графику `P`/`ABC` держать отдельными управляемыми объектами/материалами, чтобы безопасно менять костюм и текст без изменения лица/тела.
- Лицо: независимый aim глаз, blink с верхним веком, brow controls, jaw/lip shape keys; выражения формировать из переиспользуемых controls/shapes.
- Крупный план и полный рост должны использовать один и тот же mesh/rig/materials. Никакого chroma-key и смены 2D-поз вместо анимации.

## Оценочные пропорции для blockout (нужна проверка на turntable)

В качестве стартового масштаба задать высоту всей фигуры с кепкой = 1.0 условная единица. По фронтальному виду голова с кепкой занимает примерно верхнюю треть высоты; туловище в худи короче ног, кисти доходят примерно до верхней части бёдер. Это грубые отношения с маленькой картинки, а не замороженные числовые ограничения.

В blockout не добавлять мелкие детали/текстуры, пока автор не утвердил:

1. форму головы и ширину щёк;
2. размер/расстояние глаз, положение бровей и носа;
3. посадку кепки и форму головы в профиле;
4. соотношение головы, корпуса и ног;
5. силуэт худи, ширину рукавов и длину брюк.

## Известные пробелы

Скриншоты не дают чистой high-res сетки, side/rear views волос под кепкой, чистого mouth-expression sheet или понятных точных измерений. До утверждения blockout не придумывать новые постоянные черты. Если исходные изображения без UI доступны, заменить ими только производные reference plates, сохранив оригиналы.
