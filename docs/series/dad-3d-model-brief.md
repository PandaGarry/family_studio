# Первый 3D-персонаж: папа

Статус: рабочий визуальный brief v0.3 по мастерам из `docuflow`. Это **не готовая сетка и не Blender-render**. Папа выбран первым героем, потому что сохранение его сходства было главным узким местом прежней 2.5D-анимации. Пользователь подтвердил домашний верх: светлый crewneck без капюшона (2026-11-01); исходный JSON сохранён без изменений.

## Источники

Основные неизменённые файлы:

- `assets/references/docuflow/characters/dad/turnaround.png` — front / 3⁄4 / side на зелёном reference-фоне.
- `assets/references/docuflow/characters/dad/face.png` — крупный front portrait для формы лица и черт.
- `assets/references/docuflow/characters/dad/{front,three_quarter,side}.png` — отдельные кропы видов.
- `assets/references/docuflow/characters/dad/character.json` — исходные пропорции, палитра и ограничения identity.
- Происхождение, версия и ограничения использования: [`assets/references/docuflow/README.md`](../../assets/references/docuflow/README.md).

Скриншоты из `assets/references/raw/` остаются вспомогательными. Не брать из зелёного фона цвет материала/окружения; не переносить UI или следы хромакея на модель.

## Зафиксированные видимые якоря

- Взрослый мужчина с коренастым, широкоплечим силуэтом и заметным, но дружелюбным округлым лицом.
- Короткие тёмно-каштановые волосы: короткие бока/fade, выразительная текстурная верхушка; аккуратная полная борода и усы.
- Тёплые карие глаза, густые выразительные брови, широкие уши, сильная челюсть.
- На turnaround виден светло-серый верх с круглой горловиной, тёмные прямые джинсы и коричневые ботинки. **Домашний верх зафиксирован по выбору пользователя: crewneck без капюшона.** Это осознанное переопределение исходного JSON-ярлыка `hoodie_gray`; файл источника оставлен нетронутым.
- В `character.json` записаны `height_heads: 5.9`, широкое телосложение, палитра и запреты менять бороду/линию волос. Это стартовые данные, а не проверенная метрическая съёмка.

## Открытые вопросы перед детализацией

1. Нужны подтверждённые рост и соотношение папы с мамой и сыном (пока есть только предварительные оценки в головах).
2. Нужен ли отдельный вид спины/затылка для волос, шеи и одежды? На текущем листе спины нет.
3. Какие детали лица на крупном master нельзя упрощать при стилизации в Blender (форма бороды, бровей, щёк и улыбки)?

Не добавлять другие не показанные постоянные черты; моделировать только то, что подтверждено референсами или автором.

## Сборка в Blender: порядок

1. Поставить turnaround/view images как временные reference planes с единым масштабом и выровнять три вида по подошвам/макушке.
2. Сделать серый, не сглаживающий identity blockout: череп/челюсть/уши, торс, плечи/живот, руки/ноги и ступни. Без бороды, одежды с мелкими швами, волос-прядей и шейдера.
3. Сравнить один mesh в front / 3⁄4 / side / close-up. Gate: автор узнаёт папу и утверждает силуэт прежде, чем добавлять материалы.
4. Отдельными управляемыми объектами построить волосы/бороду/брови/глаза и одежду; проверить лицо крупно и семейный lineup.
5. Создать control rig для ног/рук и базовый facial rig: eye aim, полноценный blink с веками, brows, jaw и ограниченный набор visemes.
6. Проверить idle, взгляд, моргание, поворот головы, gesture и 2–3 шага с foot lock. Только рендер из работающего Blender считать proof-of-style.

## Чего не считать доказательством

- Кроп или смену поз из 2D-библиотеки.
- Чужую готовую модель с похожей одеждой.
- Старый `body3d.py`/NumPy software-render из `docuflow`: там есть полезные пропорции и заметки по IK, но документация источника сама фиксирует недостаточную детализацию/качество.
- Скриншот или ролик, если он не получен из одного проверенного Blender mesh/rig.
