# Дорожная карта Family Studio

Единый краткий трекер текущей работы. Здесь отмечаются **статус, зависимости, критерий завершения и следующий шаг**; детали модели остаются в персонажных brief, стратегия производства — в [`production-plan.md`](production-plan.md), а решения по `docuflow` — в [`docuflow-migration-review.md`](docuflow-migration-review.md).

Правило статуса: задача считается выполненной только при наличии артефакта/проверки и, когда нужно, явного одобрения пользователя. План или неподтверждённый рендер не равен готовой модели.

## Текущее состояние — 2026-11-01

**Фаза:** подготовка первого Blender-персонажа — папы.

**Сейчас:** исходники и визуальные ограничения собраны; 3D blockout ещё не создан.

**Блокер:** в текущем sandbox нет рабочего Blender/Godot runtime, поэтому нельзя честно собрать и проверить `.blend`/рендер здесь. Blender остаётся целевым инструментом; программный renderer из `docuflow` не подменяет его.

## Ближайшие действия

1. **Найти совместимый Blender runtime для этой рабочей среды** либо подготовить передачу проекта для запуска в локальном Blender пользователя. Не объявлять модель/рендер готовыми до реального запуска.
2. **Начать R3:** использовать `assets/references/docuflow/characters/dad/{turnaround.png,front.png,three_quarter.png,side.png}` и brief `dad-3d-model-brief.md`; JSON `height_heads: 5.9` пока только гибкая стартовая оценка.
3. Сгенерировать turntable серого blockout из одной геометрии; проверить front / 3⁄4 / profile при одинаковой камере и масштабе.
4. Показать blockout пользователю. Только после его решения закрыть R3 и переходить к волосам, бороде, лицу и одежде.

Если runtime остаётся недоступен, продолжаем безопасную подготовку (references, измерения, Blender Python script/technical specs), но R3–R6 остаются blocked — никакого фиктивного подтверждения.

## Решения, которые считаются зафиксированными

- Основной DCC и целевой proof: Blender; Godot — опционален, не требуется для первого персонажа.
- Первый 3D-герой: папа; затем мама и сын.
- Домашний верх папы: светло-серый crewneck без капюшона — решение пользователя от 2026-11-01. Source `docuflow` JSON не изменяется.
- Старый 3D prototype из `docuflow` — технический справочник и эксперимент, не финальный render/model.
- Не возвращаться к отклонённому 2.5D cutout как к финальному решению.
- Не брать чужую готовую модель вместо семейных героев; внешние ассеты проверять и записывать в asset ledger.

## Изменение плана

Если появляется новый reference, решение пользователя, runtime или технический блокер — добавить это сюда и в соответствующий brief/ledger. Сохранять прошлые решения и причины изменения; закрывать этап только с конкретным выходом и проверкой.
