# Family Studio

Локальный production-проект для короткого семейного мультсериала в 2–2,5D. Исходная точка — стилизованные персонажи из пользовательских референсов; целевой выпуск — вертикальный ролик 30–45 секунд.

## Рабочие документы

- [Анализ творческих ориентиров](docs/series/influence-analysis.md) — принципы выбранных мультсериалов и собственное направление без копирования.
- [Визуальная библия персонажей](docs/series/character-bible.md) — предварительный разбор образов, неутверждённый канон.
- [Производственный план](docs/series/production-plan.md) — этапы от теста 2,5D до локального MP4.
- [Первый motion study](docs/series/proof-of-style.md) — статус аниматика, ограничения и вопросы для согласования.
- `assets/references/raw/` — исходные изображения, сохранённые без изменений.

Сначала утверждаем дизайн и короткий технический тест анимации; затем — series bible, пилот, storyboard/animatic и сборка. Никакой результат не называется готовым рендером, пока его фактически не проверили.
